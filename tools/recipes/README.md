# Explicit rpx recipes

`test8.py` through `test15.py` construct proofs from model pairs using `rpx` and
its shared `rpx.lowlevel.Assembler`. They do not load historical RPA/RPX.
Each exports `build(source, target, *, source_path=None, target_path=None)`.
The paths allow recipes 12 and 13 to read their author-selected audit hints.

Maps are sparse specifications expanded by Rust, and native MappingView performs
pullbacks. Cases branches conclude explicitly; Interval and Menu use typed
specifications and results. The compiler does not discover the recipe's theorem
or search for mathematical witnesses.

```sh
python3 tools/cases.py build --manifest tools/recipes/manifest.json --out-root build/recipes
```

Use `python3 tools/cases.py --help` for exact command options. Acceptance checks
model formulations, Kernel verification and format roundtrips. New certificates
may differ in ordering and bytes from the frozen historical evidence.
