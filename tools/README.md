# Current repository tools

Run these from the repository root. The Rust `rpx` CLI performs verification;
the Python tools are auxiliary checks, not a second proof core.

| Task | Entry point |
| --- | --- |
| Case verification, RPA/RPX conversion, native recipe compile | `cases.py` |
| Manual examples and rejection checks | `check_rpx_manual.py` |
| Documentation link check | `check_docs.py` |
| Native API performance benchmark | `benchmark_compiler_api.py` |

Case deliverables are fixed current artifacts: `source.mcm`, `target.mcm`,
`proof.rpa`, `proof.rpx`, `delivery.json`, and `preparation.json`. The historical
LP-to-proof generators and their legacy model/expression bridge have been
removed. Existing proofs are verified with `rpx verify` or rebuilt from RPA 12
with `rpx assemble`; no LP input is required.

## Case pipeline

`cases.py` is the only case entry point and uses `rpx.lowlevel` and
`rpx.Proof` in-process. It never parses LP, builds legacy model
dictionaries, spawns `rpx`, or writes certificate JSON.

```sh
python3 tools/cases.py verify cases/test8
python3 tools/cases.py check cases/test8
python3 tools/cases.py check --jobs 4
python3 tools/cases.py assemble cases/test8 --write
python3 tools/cases.py disassemble cases/test8 --write
```

`verify` checks the current MCM/RPX pair and audits `delivery.json`. `check`
additionally requires canonical `RPA 12 -> RPX 11 -> RPA 12` byte equality.
Without case arguments, the commands operate on every directory under `cases/`.
`--write` replaces an artifact only after the regenerated bytes match.

The first native recipe batch is `tools/recipes/manifest.json` (test9-test15):

```sh
python3 tools/cases.py build --out-root /tmp/native-cases-9-15
```

A native recipe is a Python file exporting `build(source: Model, target: Model)
-> Proof`. It is compiled and verified by the same public API:

```python
from rpx import Proof

def build(source, target, *, source_path=None, target_path=None):
    proof = Proof(source, target)
    forward = proof.forward.map({"x": 0})
    reverse = proof.reverse.map(default="same_name")
    forward.finish()
    reverse.derive.le(reverse.upper("x") - 1)
    reverse.finish()
    return proof
```

```sh
python3 tools/cases.py compile   --source cases/test8/source.mcm --target cases/test8/target.mcm   --recipe recipe.py --out /tmp/test8-case --expect cases/test8
```

With `--expect`, compilation compares source and target formulations, verifies
the reference proof, and checks both new format roundtrips. Instruction order
and proof bytes may change. See [recipes](recipes/README.md).
