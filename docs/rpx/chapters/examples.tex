\chapter{完整可复现实例}
\label{ch:examples}

三个例子位于本手册的 \code{examples/} 子目录。每个目录包含完整 source.lp、target.lp、
严格 JSON 汇编 proof.rpa 与可读 proof.rpas，两个文本编码得到相同 RPX 11 字节。

\section{等式消元}
源模型保留等式 $x_0+x_1=1$，目标只使用 $y=x_1$；反向恢复 $x_0=1-y$。

\section{冗余行与分段恢复}
\code{examples/redundant/} 通过已有界证明冗余行，同时两个方向保留完整目标。
\code{examples/piecewise/} 使用穷尽分支实现分段恢复；每支仍须独立完成全部输出义务。
完整源文件是本手册组成部分，可直接阅读、汇编和验证。

\section{统一检查命令}
从仓库根执行：
\begin{lstlisting}
python3 tools/check_rpx_manual.py --kernel target/release/rpx
\end{lstlisting}
当前检查执行 42 个 CLI 命令：验证三个完整例子、两种文本汇编与字节往返，
并运行 12 个负例检查，覆盖错误恢复、缺失目标、非法性质字段和资源耗尽。
三个例子均各有 9 项总 Return 义务。记录保存在 \code{examples/verification.json}。
汇编阶段拒绝非法字段与执行阶段拒绝数学错误属于不同检查边界。
