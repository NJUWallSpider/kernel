\section{严格 JSON：RPA 11}
文本以 \code{RPA 11} 和换行开头，后接 Certificate JSON：
\begin{lstlisting}
RPA 11
{
  "forward": {"steps": [], "end": {"Return": {
    "map": [], "checks": ["Exact"]
  }}},
  "reverse": {"steps": [], "end": {"Return": {
    "map": [], "checks": ["Exact"]
  }}}
}
\end{lstlisting}
该证书适用于两个可行零维模型且常数目标相等的情形，仍各检查一次目标不增。
有理数字面量为字符串；枚举使用单键外部标签，例如 \code{VarLower}、\code{Return}。
缺失方向、未知字段、旧性质声明和多余字段拒绝。
直接编译 Certificate JSON 时仅省去 RPA 头，不改变证明结构。

\begin{lstlisting}
rpx assemble proof.rpa proof.rpx
rpx disassemble proof.rpx proof.rpa
rpx compile certificate.json proof.rpx
\end{lstlisting}
以上成功只表明格式转换成功。完整数值和引用义务仍须 verify。

\section{可读源语言：RPA-S 1}
RPA-S 的 1 是源语言语法版本，不选择旧 RPX 语义。
文件声明模型后给出 certificate，字段仍只有 forward 与 reverse。
命名 checks 依实际完整模型的义务绑定，例如 \code{variable["x"].lower}、
\code{row["balance"].equal} 和 \code{objective.non_increasing}。
命名项必须恰好覆盖该 Return 的义务；未知、重复或缺失项拒绝。
引用也可使用局部名称、行名称和表达式语法，确定性降低为相同底层对象。

\begin{lstlisting}
rpx assemble proof.rpas proof.rpx
rpx disassemble-source --models source.mcm target.mcm \
  proof.rpx proof.rpas
\end{lstlisting}
完整语法与 CLI 顺序以 \code{docs/RPA_SOURCE.md} 为准。
下一章提供实际可运行文件；Python 编写接口详见 \code{docs/COMPILER_API.md}。
