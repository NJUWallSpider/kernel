\chapter{版本边界与迁移}
\label{app:revisions}

MCM 1 维持原编码。RPX 11 是有意不兼容的简化：证书仅含 forward、reverse，
所有根均为完整 MI 域，所有 Return 都检查目标不增。
生产内核没有旧版本解码分支，也没有 Contract、projection、inverse、LP、点、双射、
目标层、半空间根限制、ImproveReturn 或 PositiveRefutation 接口。

保留的六种 Step、两种 DerivationEnd 和八种 End 在固定目标下使用。
Flow、Interval、Menu、Signed、Subflow 是构造所需输出的方法，不是不同的认证目标。
Absurd 和局部分支仍必要，可用于证明不可行域或建立分段映射。

\code{tools/migrate_mi_opt.py} 通过独立旧二进制读取历史证书，选择两个全域 MI 方向，
删除其末尾附加性质义务，输出新证书并要求完整验证。
没有合适双向构造的证书不能靠改名迁移。81 个当前案例均已逐项通过，
原 83 个历史文件继续保留原字节和原验收含义。

旧版更多性质的数学结果可以作为历史研究记录阅读，不能解释为当前 API 的功能。
数值最优解恢复执行器仍未提供；目前验证的是构造的数学合法性。
